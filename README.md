# personal-website
A CV-style personal website for me, a second-year Bachelor student in Business Informatics at Epoka University.

## Features

- Personal introduction and CV presentation
- Education section
- Technical skills section
- University projects
- Work experience summary
- Contact details

## Technologies

- React
- Vite
- JavaScript
- HTML & CSS

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 5050
```

Open the site at `http://localhost:5050/`.

## Build

```bash
npm run build
```

## Project structure

- `src/` — React source files
- `index.html` — main HTML entry
- `package.json` — dependencies and scripts
- `vite.config.js` — Vite configuration
- `README.md` — project documentation

## Notes

This project is a simple, clean portfolio/CV website for Erkli Boka, ready to deploy or share as a GitHub repository.
